## Agents that improve. A factory that learns to build better ones.

Ebiose is an [Inria](https://www.inria.fr/en) (the French national research institute behind
[scikit-learn](https://scikit-learn.org)) spin-off building an open-source framework for creating and evolving AI
agents. You define a task and how to measure success. Ebiose builds, evaluates, and improves
agents tailored to it.

Our ambition goes further: improve not only the agents, but the way they are created. That
is what we have spent the past 18 months building into our new **Genomic Engine**.

The new framework is in active development. Its code is not public yet. It will launch here
in **November 2026**, under the MIT license.
